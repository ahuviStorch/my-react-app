שאלה 2: איך מריצים פרויקט React שכבר הורץ בעבר?

תשובה:

פותחים את הטרמינל בתיקיית הפרויקט.

מריצים את פקודת ההפעלה (npm run dev בפרויקטים של Vite, או npm start בפרויקטים של CRA).

פותחים בדפדפן את הכתובת המופיעה בטרמינל (למשל http://localhost:5173).

שאלה 3: מה משמעות השגיאה ENOENT ואיך פותרים אותה?

תשובה:
השגיאה ENOENT מתרחשת כאשר הטרמינל נמצא בתיקייה ראשית שאינה מכילה את הקובץ package.json.
פתרון: יש לנווט בטרמינל לתוך תת-התיקייה שבה ממוקם הפרויקט באמצעות הפקודה:
cd my-react-app

שאלה 4: מה תפקיד השורה export default App בסוף הקובץ?

תשובה:
שורה זו מייצאת את הקומפוננטה הראשית כדי שקבצים אחרים בפרויקט (כמו main.jsx) יוכלו לייבא אותה ולהציג אותה במסך.

שאלה 5: איך מועברים נתונים (Props) ואיך נקבע סדר התצוגה?

תשובה:

הנתונים הסטטיים מוגדרים בקומפוננטת האב (App.jsx) ומועברים לקומפוננטות הבנים דרך מאפיינים (Props).

סדר התצוגה במסך נקבע בדיוק לפי סדר הופעת הקומפוננטות בתוך ה-return של קומפוננטת האב (App.jsx).
